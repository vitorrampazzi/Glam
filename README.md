# 💅 Glam - Plataforma de Beleza em Casa

**Glam** é uma plataforma digital onde os clientes podem contratar serviços de beleza diretamente com profissionais especializados, para atendimento no conforto de casa. Com um catálogo de cabeleireiros, barbeiros, manicures e maquiadores, o site oferece uma experiência moderna, prática e visualmente atrativa.

## ⚙️ Funcionalidades

- Cadastro e exibição de profissionais da beleza
- Visualização de cards com nome, categoria e imagem do profissional
- Pop-up com portfólio de até 4 fotos por profissional
- Filtragem por categoria:
  - Cabeleireiros
  - Barbeiros
  - Manicures
  - Maquiadores
- Agendamento de serviços com data, horário e localização
- Layout 100% responsivo para dispositivos móveis

## 🚀 Tecnologias utilizadas

### Front-end
- HTML5
- CSS3
- JavaScript
- React.js
- Tailwind CSS

### Back-end
- Node.js
- Express.js

### Banco de dados
- MongoDB (via Mongoose)

### Outros
- React Modal (para pop-ups)
- Swiper.js (para carrossel de portfólio)
- Vercel (deploy Front-end)
